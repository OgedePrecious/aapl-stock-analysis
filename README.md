# AAPL Stock Analysis

A Python-based analysis of Apple Inc. (AAPL) historical stock data from 2020 to 2025, examining price trends, returns, moving averages, and volatility to better understand historical market behaviour.

---

## Project Summary

This project analyzes historical AAPL stock data using Python and Pandas. The analysis transforms daily stock data into useful indicators for examining price movements, trends, returns, and volatility.

The project combines data preparation, time-series analysis, feature engineering, and visualization to identify patterns in AAPL's historical performance.

---

## Analytical Objectives

The analysis aimed to:

- Examine AAPL's historical closing-price trend.
- Analyze weekly and monthly price movements.
- Measure daily price changes and percentage returns.
- Use moving averages to identify short-term and broader price direction.
- Analyze periods of increased price volatility.
- Create engineered features that make the raw stock data more useful for analysis.

---

## Analysis Performed

The analysis included:

- Data quality checks
- Missing-value and duplicate checks
- Data transformation and restructuring
- Yearly summary analysis
- Weekly and monthly analysis
- Daily percentage returns
- 7-day moving average
- 30-day moving average
- Monthly returns
- 30-day rolling volatility
- Daily price range

---

## Key Findings

- AAPL showed substantial long-term price growth from 2020 to 2025, despite temporary declines.
- Short-term price movements showed noticeable fluctuations within the broader upward trend.
- The 7-day and 30-day moving averages helped clarify the underlying price direction.
- Most daily percentage changes were relatively small, although occasional sharp movements indicated periods of higher volatility.
- Feature engineering made the raw stock data more useful for monitoring price trends, returns, and volatility.
